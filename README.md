# Anime Analysis

基于 YOLO 的动漫番剧人物识别与管理系统课程实训项目。

系统面向单机桌面环境，采用“人物检测 → 人物分类 → unknown 拒识 → 人物与番剧映射 → 多人结果聚合”流程。当前仓库先同步需求、设计、训练实施计划和四周进度安排，训练代码与桌面应用将在后续阶段按计划提交。
